# Regulatory Intelligence Platform

Локальное приложение для управления нормативными правовыми актами и проектами.

## Требования

- Node.js v20+ (уже установлен)
- npm (уже установлен)

## Установка

Все зависимости уже установлены. Просто запустите приложение:

```bash
npm start
```

## Структура

- `main.js` - главный процесс Electron, работа с базой данных SQLite
- `ri_platform.html` - интерфейс приложения
- `package.json` - конфигурация проекта

## База данных

Приложение использует SQLite базу данных, которая автоматически создаётся при первом запуске в директории пользователя:
- Проекты НПА (проекты нормативных актов)
- Принятые акты (действующие НПА)
- Продукты (категории продукции)
- История изменений

## Возможности

1. **Дашборд** - общая статистика и список проектов
2. **Принятые НПА** - список действующих актов
3. **Календарь изменений** - хронология событий по всем проектам и актам
4. **Продукты** - фильтрация по категориям продукции

### Управление данными

- Добавление новых проектов и актов через кнопки в интерфейсе
- Редактирование существующих записей
- Перемещение проектов в статус "Принятые" при их утверждении
- Все изменения синхронизируются между всеми разделами приложения
- История изменений сохраняется автоматически

## Примечание

Приложение работает локально без необходимости регистрации. Данные хранятся в SQLite базе на вашем компьютере.
